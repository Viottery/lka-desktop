# Windows Native Runtime Guide

This guide consolidates the native Windows run path for this repository,
including backend runtime setup, desktop pet launch options, and daily
maintenance commands.

Scope:

- Windows 10/11
- No Docker, no WSL
- FastAPI + agent runtime + shell/action path
- Desktop pet window (Python native or Java launcher)

## 1. Native Folder Map

Key Windows-native files and folders:

- `scripts/setup-agentic-rag-windows-native.ps1`: one-shot bootstrap script
- `run-native-local.ps1`: local app launcher with PID/log handling
- `scripts/start-desktop-pet.ps1`: Python desktop pet launcher
- `scripts/start-desktop-pet-java.ps1`: Java desktop pet launcher
- `requirements-windows-agent.txt`: lightweight native dependency set
- `.env`: runtime config generated by setup script
- `.runtime/`: local PID/runtime metadata
- `logs/`: app and launcher logs
- `data/memory/conversations.db`: local conversation store

## 2. Prerequisites

- PowerShell 5.1 or newer
- Git
- Python 3.11

Optional:

- Java 21 (for Java desktop pet launcher)

Install/check Java:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\setup-java-env.ps1 -InstallPrereqs
```

## 3. One-Shot Native Bootstrap

From repository root:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force

.\scripts\setup-agentic-rag-windows-native.ps1 `
  -UseHttps `
  -OpenAIApiKey "<OPENAI_API_KEY>"
```

What the script does:

- checks/installs Git and Python 3.11 (with `-InstallPrereqs`)
- creates `.venv`
- installs `requirements-windows-agent.txt`
- writes native-friendly `.env`
- starts `uvicorn` on `127.0.0.1:8000`
- writes PID to `.runtime/native-app.pid`
- writes logs under `logs/`

## 4. Native `.env` Defaults

The native setup script writes these core defaults:

```dotenv
LOCAL_RAG_TRANSPORT=tcp
LOCAL_RAG_HOST=127.0.0.1
LOCAL_RAG_PORT=8765
LOCAL_RAG_ENABLED=false
RERANKER_ENABLED=false
SHELL_PROVIDER=powershell
SHELL_CONVERSATION_WORKSPACE_PARENT=agentic-rag-workspaces
CONVERSATION_STORE_PATH=data/memory/conversations.db
```

Rationale:

- bring up chat/agent/shell paths first
- keep local RAG and heavy model startup disabled initially
- make native startup fast and stable
- keep one working directory per conversation under desktop by default
- allow read access broadly while restricting writes to the active conversation working directory

### UTF-8 Encoding Baseline (Recommended)

To avoid mojibake on Windows terminals and PowerShell command output, keep runtime and shell execution on UTF-8:

```powershell
$env:PYTHONUTF8 = "1"
$env:PYTHONIOENCODING = "utf-8"
[Console]::InputEncoding = [System.Text.UTF8Encoding]::new($false)
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new($false)
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
chcp 65001 > $null
```

`run-native-local.ps1` now sets `PYTHONUTF8=1` and `PYTHONIOENCODING=utf-8` by default before starting backend services.

## 5. Start, Stop, and Health

Start native app:

```powershell
.\run-native-local.ps1
```

Stop native app:

```powershell
Stop-Process -Id (Get-Content .\.runtime\native-app.pid)
```

Health check:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

Log tail:

```powershell
Get-Content .\logs\native-app.out.log -Tail 100 -Wait
Get-Content .\logs\native-app.err.log -Tail 100 -Wait
```

## 6. Desktop Pet Launch (Windows)

Python launcher (recommended default):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop-pet.ps1
```

Python fallback modes:

```powershell
# Browser debug mode
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop-pet.ps1 -Browser

# Static native fallback window
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop-pet.ps1 -Static

# PyWebView host fallback
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop-pet.ps1 -WebView
```

Java launcher:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop-pet-java.ps1
```

Java Spine mode:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\start-desktop-pet-java.ps1 -Spine
```

## 7. Native Smoke Commands

Shell/action path:

```powershell
$body = @{
  question = "command: Write-Output agentic-rag-native-ok"
} | ConvertTo-Json -Depth 8

Invoke-RestMethod `
  -Method Post `
  -Uri "http://127.0.0.1:8000/chat" `
  -ContentType "application/json" `
  -Body $body
```

Direct answer path:

```powershell
$body = @{
  question = "What is HTTP?"
} | ConvertTo-Json -Depth 8

Invoke-RestMethod `
  -Method Post `
  -Uri "http://127.0.0.1:8000/chat" `
  -ContentType "application/json" `
  -Body $body
```

## 8. Daily Maintenance

- keep `.venv`, `.runtime`, `logs`, and local DB out of git commits
- update dependencies only through `requirements*.txt`
- use `scripts/setup-agentic-rag-windows-native.ps1 -SkipDependencyInstall` for quick restarts
- use `-RecreateEnv` only when config needs a full rewrite

For desktop pet frontend internals, see
