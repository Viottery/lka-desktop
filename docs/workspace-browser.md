# 工作区目录浏览

在工作台点击当前工作区旁的“切换”，或设置里工作目录右侧的“浏览”，打开目录选择窗口。
左侧是本机磁盘和最近使用的位置；右侧只显示文件夹。单击文件夹进入，向上按钮返回
上一级；可以筛选、显示更多，或在顶部输入路径并点击“前往”。

浏览不创建文件夹、不切换会话目录。点击“使用此目录”才调用现有工作区绑定接口；
点击取消、关闭或 Escape 保留原目录。任务进行时可以浏览，但不能切换正在使用的
工作区。后端拒绝目录时，错误留在选择窗口中，原目录保留。手动填写路径仍可使用。
确认切换后，工作区摘要、设置输入和文件列表同步更新。布局适配小窗口及手机页面。

## 目录来源与限制

目录来自前端服务所在的电脑；后端仍校验工作区访问范围。WSL 后端沿用已有 Windows
盘符路径桥接，不新增后端接口。前端 `GET /pet/workspace-directories` 仅返回目录名称、
路径、父目录和本机磁盘，支持 `path`、`query`、`offset`、`limit`。每页最多 200 项，
扫描最多 10,000 项，截断会提示缩小筛选范围。

沿用本机访问策略，目录枚举仅允许本机页面；远程页面仍可手动输入电脑上的目录路径。
远程新会话的工作区创建通过单独启用的工作台来源访问，只允许配置好的父目录；见
[移动工作台配置](mobile-workbench.md#远程访问配置与修复2026-10-07)。
不浏览网络盘、UNC、Windows 链接或挂载转接目录，不读取文件正文。目录不可访问或
已被移动时提供错误提示。没有改变后端、监听地址或凭据配置。

## 验证（2026-10-07）

- 前端 Windows 原生 Python：9 条目录接口测试通过，覆盖本机与跨站访问、固定磁盘、
  路径规范化、链接跳过、分页筛选、默认目录和不存在目录不创建。
- Windows Chrome 合成聊天回归通过：目录导航、筛选、分页、取消无绑定写入、确认绑定、
  绑定失败回退、手机布局和 Escape 关闭；现有发送、实时 SSE、原生桥接和草稿检查通过。
- 移动端五种屏幕尺寸回归通过。上述测试使用模拟会话，不发送真实 QQ 消息或模型任务。
