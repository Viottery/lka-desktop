# 记忆模块前端适配交付（2026-10-02）

## 范围

本次只修改前端页面、Java WebView 通信适配、前端测试和文档。没有修改后端代码、数据库或配置，没有重启后端。现有桌宠形象、动作、拖动、消息发送、Markdown 和会话回收站交互保留。

执行清单：[frontend_memory_adaptation_todo.md](frontend_memory_adaptation_todo.md)。

## 使用入口

- 会话工作目录栏的“记忆”打开记忆中心；工作台右侧也提供“记忆与自动学习”。
- 桌宠快速窗口提供记忆查看、保存、纠正、候选确认、停止使用和学习开关。后台资源、高级设置、文件和导出操作集中在工作台，快速窗口可直接打开工作台继续管理。
- 用户消息下的“记住这条”打开编辑框；在该消息中选中文字时保存选中部分。保存前可以确认作用范围、类型和个人信息标记。最多 500 字，长消息不会被静默截断。
- “项目内新建”复用当前工作目录。普通“新任务”继续使用会话独立工作区；切换目录不会自动迁移项目记忆。

## 已交付功能

### 记忆与来源

全局/当前项目切换、分页载入、已载入内容搜索、候选与冲突状态、来源标识和时间。来源接口没有正文，页面不会伪造原始消息或会话跳转。

新增是用户确认的记忆。纠正和候选确认提交 `PATCH` 及 `expected_version`，按后端规则产生新记忆 ID；旧条目被替代。遇到 409 保留草稿，显示重新载入入口；已被替代或撤回的原 ID 不能继续纠正。切换项目后，旧项目草稿不会误保存到新目录。

“停止使用”需要在页面明确确认，通过带版本号的 `DELETE` 撤回，原始来源与审计仍保留。页面没有实现后端未提供的记忆历史和恢复功能。会话删除/恢复提示说明：删除撤回记忆来源，恢复会话不会自动重新发布记忆。

全局和当前项目学习开关立即生效，关闭不会删除或停用已有记忆。高级设置中关闭整个记忆模块与关闭自动学习的含义不同。

### 上下文与后台任务

当前会话展示上下文估算、预算、近期消息数、整理中状态与备用整理提示。保留原始历史，不显示原始 prompt，不把整理状态当成整轮任务的完成进度，也不虚构百分比。

工作台展示后台任务状态、尝试次数、失败类别、队列数量和近 24 小时调用 token；配置了单价时显示估算费用，明确不是账单。可按状态和当前会话筛选。支持后端允许的记忆学习/上下文整理任务重试，以及处理中任务取消；提交 `expected_updated_at`，冲突后刷新状态。取消不撤销已完成的效果。

浏览器使用带请求头的 SSE 健康快照，失败时由定时 JSON 请求补充；Java 快速窗口通过异步桥接请求，使用轮询。隐藏页面暂停状态更新；这些后台请求不会禁用聊天输入。

### 高级设置

从后端 schema 生成记忆与后台资源字段，遵守类型、整数和数值范围；分别展示当前生效值与待生效值。仅提交变化字段，并带 `expected_revision`。冲突保留表单，用户自行重新载入。

可选择后台服务商和模型，支持恢复配置文件默认值。保存、恢复均需要后端重启；页面显示待生效提示，不调用重启服务。

模型接口的动态目录没有标记每个模型是否已配置，而后台配置只接受已配置模型。因此动态目录暂时仅提供默认模型、当前已生效及已保存的后台模型；纯配置目录提供全部配置模型。其余选择需要后端提供明确的逐模型配置标记。

### 文件与导出

JSON 导出读取全部分页，包含当前条目和候选。导出带前端生成时间，不是历史数据库备份，也不是事务快照；并发编辑时应重新导出。

支持 MEMORY.md 读取、同步生成、文件修改预览、单条修改导入。文件由本地编辑器修改；导入前重新检查文件哈希与修改内容，多条修改不允许提交。生成时由后端保护已有手动修改，不覆盖冲突文件。

项目目录搬迁独立于普通目录切换，只迁移项目记忆身份，不移动磁盘文件；之后需要在会话中切换到新目录。

## 通信与兼容性

新增接口统一使用 JSON，浏览器使用 fetch，Java 使用 HTTP/1.1 异步 HttpClient。Java 仅允许指定记忆、后台配置、模型及上下文接口，拒绝外部 URL、未知查询参数和路径跳转。回调 ID 带页面随机标识，避免旧页面响应与新页面请求混淆。

访问令牌在记忆中心连接设置中填写，仅存在当前页面内存，通过 `Authorization: Bearer` 发送；不进入 URL、localStorage 或日志。关闭/刷新页面后需要重新填写。若后端未设置令牌，本机访问可以留空。

401/403 提示连接或权限问题；404 提示接口兼容性；409 保留编辑并要求重新载入；断线和超时展示可理解的错误。旧 Java 桌宠缺少桥接时阻止写入并提示重新启动前端。
