## 使用方式

左侧会话列表顶部“项目”或右侧设置中的“项目与会话”打开管理页面。快速窗口可先打开会话列表再进入项目；界面在窄窗口中按单列排列，列表与会话区域独立滚动。

“登记目录”把一个已存在、受允许的工作目录登记成项目，不创建文件夹。Windows 盘符/UNC 自动使用 Windows 平台字段；绝对 Linux 路径使用 Linux 字段，也可手动选择 macOS。Windows 到 WSL 的实际映射由后端负责。

项目详情支持改显示名称，不修改磁盘文件夹。保存使用 `expected_revision`；冲突保留输入，点击“重新载入版本”可查看最新名称后继续保存。项目详情提供项目下全部会话的分页列表和标题/消息搜索。会话被软删除后不计入项目会话数，恢复后重新计入；项目页面重新打开/刷新会向后端获取最新状态。

“在此项目新建会话”直接提交 `POST /sessions` 的顶层 `project_id`，读取嵌套 `session` 和 `messages` 响应，再切换到新会话。目录和项目身份采用后端响应。不同会话保留各自消息和摘要，但共享项目目录及项目记忆，文件写入不是隔离的。

工作目录栏的“项目内新建”使用同样的流程，未登记目录先调用 `POST /projects`。普通新任务仍使用原有独立工作区；重新打开桌宠窗口的默认新任务行为保留。当前任务处理中不允许通过项目面板切换或新建会话。

当前项目的“项目记忆”直接打开对应作用域的记忆中心；其他项目需要先打开其会话，以免将记忆保存到错误目录。已有会话切换目录会同步新的项目 ID，不移动历史消息。

## 协议与状态保护

项目功能复用 `LkaMemory.request`，浏览器 fetch 和 Java 异步 HttpClient 提交相同 JSON。Java 允许 `/projects` 列表/登记/详情/重命名/会话查询，`POST /sessions` 项目创建及会话详情读取；查询参数增加 `q`、`project_id`，仍拒绝外部 URL、路径跳转和 URL 令牌。

项目连接设置与记忆中心共用同一个页面内存令牌，通过 Bearer 请求头发送，不写入网址、localStorage 或日志，不跨页面自动共享。401/403 引导连接设置，404 提示内容或后端版本，422 展示字段/目录校验原因。

项目和会话列表都有请求序号，快速切换/搜索或关闭页面后，旧响应不会覆盖当前列表。项目会话接口没有 `next_offset`，按返回条数判断是否可能还有下一页；项目列表使用后端 `next_offset`。登记/新建避免重复提交，表单弹层打开时聊天快捷键不会意外新建任务。

## 当前边界

后端不提供项目删除、无目录虚拟项目、自动合并或文件夹创建/搬迁，因此页面不提供这些操作。已有项目记忆的显式目录身份迁移仍在记忆中心，和改名、切换目录分开处理。
