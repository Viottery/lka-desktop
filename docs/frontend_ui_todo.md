# 桌宠与工作台 UI 改造任务

目标：保留桌宠和右键展开的交互，用小窗处理快速任务，用大窗口处理多会话和复杂工作。

## 交付清单

- [x] 盘点现有桌宠、三种 Windows 宿主和新后端的会话接口；保护仓库中已有修改。
- [x] 统一快速任务面板入口，保留桌宠右键菜单，并提供一键打开工作台。
- [x] 将快速面板简化为会话、工作区、对话和输入，按需展开会话列表和设置。
- [x] 为大窗口提供常驻会话列表、对话区和工作设置区；在窄屏下自动收起侧栏。
- [x] 为每个新会话在 Windows 文档目录创建独立工作区，并在首轮任务前绑定后端会话。
- [x] 支持按会话切换已有工作目录；支持调整模型、审查方式和流式输出，并保留索引入口。
- [x] 统一主要窗口、按钮、菜单、输入框、下拉框、空状态及确认状态的视觉语言。
- [x] 支持键盘焦点、Esc 关闭浮层、Ctrl/Cmd+K 聚焦输入、Ctrl/Cmd+N 新建会话和减少动画偏好。
- [x] 为工作区创建接口补充本机访问限制与路径校验测试。
- [ ] 在 Windows 原生宿主中逐项进行视觉和真实后端交互验收。

最后一项需要在 Windows 图形桌面与运行中的本地后端上完成；其余项目在代码层完成。
