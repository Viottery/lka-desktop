# 真理

桌宠默认打开轻量的真理对话，关闭后重新打开继续使用同一个助手。窗口保留身份栏、管理状态和一条需要处理的任务提醒；完整目标和交付记录位于工作台。底部「新任务」进入普通独立任务，「真理」在当前窗口返回助手。

工作台左侧固定「真理」入口。普通会话与助手对话独立，切换入口保留原草稿。快速窗口的活动选择与普通工作台分开保存，打开桌宠不会切走工作台正在查看的会话。前端启动时就在后台预连接真理并预载跟进信息，不切换当前普通任务。之后切换入口复用已准备的持久会话、对话及游标，不重复建立连接；普通任务期间仍有界刷新跟进。只有手动「重新连接默认助手」才重新核对默认身份；若身份更换，在当前工作台切换，原会话和草稿仍按会话保留。真理使用后端默认 manager 的持久会话；关闭界面不取消任务。

真理直接使用工作台中央的对话与输入框，不弹窗、不嵌套网页；侧栏保持可用，可随时切回普通任务并恢复各自草稿。沿用统一的运行暂停/继续、补充回答和安全审查交互。右侧跟进面板分为：

- 待处理：从主管事件读取等待请求，再核对原运行的当前状态。点击打开原任务处理，主管不能替用户审批。提醒较多时分批核对，已经确认等待的任务会保留到状态变化，不随历史事件截断消失。
- 目标：读取持续跟进目标及调度状态；绑定事项完成或取消时优先显示事项状态。「和真理讨论」将目标编号和内容放进对话草稿，仍需用户发送。
- 交付记录：打开对应会话和运行查看回复。交付并不自动表示业务目标完成。

新主管默认「管理已暂停」，可对话和读取状态。点击「启用管理」允许整理事项和委托任务；「暂停管理」不取消已经独立运行的任务。此按钮不修改后端自主运行或调度配置。并发修改使用 controller revision 校验，冲突后读取最新状态，请用户再次决定。

## 连接与阅读位置

前端加载后预先准备真理，普通任务保持当前选择。返回真理复用已载入的会话和活动事件流，切换普通任务不取消真理的订阅；真正网络中断时沿用事件游标恢复。手动重新连接才重新核对默认身份。桌面桥接使用请求标识区分并发流，旧版无标识回调仅在归属唯一时接收。页面关闭后不保留网络连接，后端运行继续。

真理和普通会话分别记住最后阅读的消息与偏移，按后端地址、会话和工作台／快速窗口隔离保存。首次进入定位最新；上翻历史后，新消息、重绘或尺寸变化保留阅读位置，已经贴底时继续跟随最新。快速窗口发送新问题时从提问开头阅读，长回复增长不会强行拉到底。位置缓存在本机，上限100条，不保存消息正文；浏览器禁用存储时退化为当前页面内记忆。

## 多终端连接

多个已授权终端可以连接同一后端的默认真理，共用持久会话和消息历史。任务事件通过原运行的事件流读取，队列和跟进状态通过轮询核对；终端根据新取得的运行编号接续后续回复。
不同终端发出的消息按后端受理顺序处理，界面保留消息和回复，不展示内部处理状态标签。
草稿和阅读位置保存在各浏览器本地，不跨设备同步；同一浏览器的同源窗口可能共用本地记录。

## 连续发送与排队

支持消息队列的后端允许在真理回复期间继续发送消息。收到后端回执后，
消息在后台顺序处理；当前轮结束后为下一条开启新轮。发送未确认的消息可用原消息标识重试核对，避免重复入队。
后发消息不注入当前运行。关闭窗口或刷新页面后，可重新读取消息状态并连接当前运行。
暂停或等待审批／答复时，后续消息仍可排队；队列不能代替原操作的确认。
运行失败或取消会暂停后续消息；输入框为空时，使用原有的继续图标处理剩余消息，不自动重试失败请求。发送失败时仅在消息旁显示重试图标，不显示常驻数量、排队或完成标签。
切换到普通任务期间仍跟踪真理的队列和后续运行；返回时复用订阅，保留普通任务的草稿与阅读位置。首次发现的运行按实际暂停、等待或运行状态展示；继续队列不等于恢复暂停任务或批准操作。
普通任务会话沿用原发送方式。后端不支持队列时，助手保留原有运行控制与发送限制。手动重新连接默认助手会重新核对队列资格。

## 后端与兼容

需要包含 `/managers/default`、主管读写与 goals/events/deliveries 端点，以及 `/sessions/{sid}/runs` 的后端版本。对话仍使用通用 Agent API。默认主管被删除、功能未启用、接口版本不支持分别显示连接原因，不创建普通会话替代主管。

原生快速窗口的默认页面使用 `assistant=quick`。真理使用主 WebView 和原生输入框，保留中文输入法、附件与运行控制；完整工作台使用同页主对话和跟进面板。显式 session/run 链接保留原任务身份。

主管不自动创建或绑定普通会话的工作目录。从默认助手、原会话链接或内嵌对话连接尚未设置任务父目录的主管时，前端服务解析系统文档目录或已配置的默认工作区父目录，仅准备父目录，再使用 controller revision 校验保存到独立的 `default_execution_workspace`；已有主管配置保留。同步失败会显示连接原因并提供重试。后端为主管派发的独立任务创建子目录。内部派发、后台唤醒和任务报告输入按服务端结构化来源排除出对话气泡；真正的助手交付仍显示，旧缓存会在同步后修正。历史同步会核对请求发出时的会话消息快照，延迟响应不会覆盖期间已经完成的新一轮对话。浏览器同源代理和 Java 桥接只放行具体接口和分页参数。凭据沿用现有本机配对机制，不进入 URL。普通任务与助手按会话隔离草稿和模型偏好；主管会使用后端自己的模型设置。

旧后端的原待办助手保留兼容：仅明确关闭管理功能，或404后成功核实 OpenAPI 缺少管理接口且提供普通会话/Agent接口时，才沿用普通待办助手。真理入口始终不降级；探测失败不会新建替代会话。

界面可重新接回主管尚未结束的根运行。普通会话与主管会话均支持后端占用冲突：保留本次未发送的文字和附件，连接原任务并恢复控制，不自动抢占。响应按原会话和发送轮次核对，旧窗口的延迟响应不会覆盖新任务。浏览器代理、原生桥接与直连统一识别默认助手已删除的后端错误。待处理只展示后端已记录的等待事件，不能替代完整委托任务清单。当前后端尚无 HTTP 关联独立任务总览接口；可在对话里请求主管查询进展。

事项缓存升级到 v2，用户清单、日历和规划进度默认排除 internal 记录。完整同步仍保存 visibility 变更，使用户事项转为内部事项时能立即从个人视图移除。开启后端内部事项写入前必须升级相关前端。

## 快速窗口设置

底栏的星形图标返回真理，加号图标创建独立任务；悬停可查看名称。齿轮打开对话设置，提供模型、安全审查和实时回复显示，并通过「应用更改」保存。真理模型单独保存到当前管理会话；独立任务的模型沿用共享默认设置。更改用于后续新运行，不打断当前任务。

安全审查选择只作用于后续前台对话，后端可要求更严格的审查；主管高风险操作仍可能需要人工确认。并发更改助手设置时，保留本次选择并读取最新版本，需要再次应用。

桌宠形态、自动动作、互动和大小位置设置收进「桌宠外观与行为」，默认折叠。
