# 跨终端文件

手机、平板和桌面工作台使用同一个会话工作区。目录与文件位于运行前端服务的电脑上；
手机只负责选择本机上传文件和接收下载，不直接连接第二个后端端口。

## 使用

1. 打开工作台右侧“文件”，或手机底部“工作区”。
2. “切换目录”浏览电脑磁盘与文件夹；确认后才切换当前会话的工作区，取消保留原目录。
3. “上传到这里”选择一个或多个文件，按顺序保存到当前目录；进入子文件夹后上传保存到
   该子文件夹。每个文件最多 64 MiB，可传输任意格式。
4. 文件行右侧的下载图标下载到当前设备，由浏览器决定保存位置。单个文件最多 128 MiB，
   无法预览的文件也可下载。

传输列表显示文件名、大小、进度和原目标目录，可以取消、重试、移除或清除已完成记录。
同名文件不覆盖：新上传另存为 `文件名 (2).扩展名`，继续重复会递增序号。
上传期间可以继续对话；切换界面不会把传输目标改成另一个目录。若后端会话工作区在
上传完成前被切换或会话被删除，保存会被拒绝；回到原会话及目录后才能重试。
已经保存的文件不会因移除传输记录而删除。取消未提交的上传会清理临时文件；若取消时
电脑已经完成提交，应刷新目录确认保存结果。断网后可以重试，不实现断点续传。

新任务可以先上传文件，无需先向 Agent 发消息。前端为该任务准备并绑定独立工作区，
不会启动模型运行。输入框草稿保留。

**“上传到这里”是文件传输；输入框的“＋”是给 Agent 添加附件。**
传输文件不会自动触发解析、索引或 Agent 任务，也不受每轮 4 个聊天附件的限制。
下载先接收文件，再交给浏览器保存；传输记录的完成表示已交给浏览器，不代表操作系统
最终保存完成。刷新页面不会删除电脑上的文件，未完成的浏览器传输与重试记录不会恢复。

## 配置与目录边界

沿用[移动工作台](mobile-workbench.md)已配置的 `LKA_WORKBENCH_ORIGINS`，支持本机页面及
完整来源精确匹配的远程页面。保持现有可信组网入口，不增加监听端口或浏览器凭据。
来源检查不是登录系统。Tailscale 的设备准入和 ACL 仍由部署者管理。

目录浏览来自电脑固定磁盘，不枚举网络共享。文件传输每次向固定后端重新读取该会话的
工作区，并校验请求的工作区快照；上传在提交前再次校验。路径仅接受工作区内相对路径，
不允许路径穿越、符号链接、Windows junction/reparse 路径、设备名及 ADS。
临时上传流式写盘，成功后以不覆盖已有文件的方式发布，失败清理临时文件。
下载只允许普通文件，使用 attachment、octet-stream、nosniff 和 no-store。
本次没有提供删除、重命名、覆盖文件或执行程序的文件管理操作。

Windows 前端使用后端会话中原始的 Windows `workspace.path`，不把 WSL 的
`workspace.backend_path` 当成 Windows 路径。Windows 目录绑定给 WSL 后端时，后端沿用
已有盘符桥接；双方仍使用各自数据库。如果会话选的是仅存在于 Linux 后端的目录，
Windows 前端无法直接传输该目录，界面提示切换到电脑可访问的工作区。

## 前端接口

| 方法与路径 | 行为 |
| --- | --- |
| `GET /pet/workspace-directories` | 已授权的本机/远程页面浏览电脑文件夹，沿用分页筛选 |
| `POST /pet/workspace-files/{session_id}/upload` | `path` 为目标相对目录，`workspace` 为当前工作区快照 |
| `GET /pet/workspace-files/{session_id}/download` | `path` 为相对文件路径，`workspace` 为当前工作区快照 |

上传请求为 `application/octet-stream` 原始文件字节，`X-Filename` 为百分号编码的 UTF-8
文件名。成功返回 `filename`、`path`、`size_bytes`、`renamed`。无工作区或工作区已变更
返回 409；不存在会话/文件返回 404；超过大小限制返回 413；来源不允许返回 403。
固定上游连接失败返回 502。没有新增或修改后端 API。

## 验证

`npm run test:files` 使用合成远程域名、合成会话和真实 HTTP 文件字节，覆盖手机/平板
四种视口、目录选择取消/确认、原始二进制上传、同名保留、子目录上传、通用下载、
不能预览时仍可下载，以及取消和重试。截图保存到忽略目录 `.runtime/workspace-files-preview/`。

Python 回归：`python -m unittest tests.test_workspace_directories tests.test_workspace_file_transfer`。
测试使用临时目录和模拟后端，检查来源、会话/工作区快照、路径边界、临时文件清理和
Windows 原生读写。不使用真实聊天内容，不启动 Agent 或发送 QQ 消息。
