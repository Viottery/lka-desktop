# 手机与平板工作台

浏览器访问前端的 `/desktop-pet/mobile.html`，进入适合触屏的理事所工作台。
入口会跳转到共享聊天页并设置 `mode=work&layout=mobile`；已有的 `backend`、
`session_id` 等查询参数保留。例如，在已能访问前后端的浏览器中使用：

```text
/desktop-pet/mobile.html?backend=<已配置的后端地址>&session_id=<已有会话 ID>
```

未指定 `backend` 时，移动页面使用同源 `/workbench/` 网关，由前端服务访问固定的本机
后端；手机只需要访问前端的现有端口。显式指定可访问的后端仍可使用；远程浏览器打开
带有 `localhost`/`127.0.0.1` 后端参数的桌面链接时，会改走同源网关。本页面不改变
后端监听、端口、Agent 审核或组网配置。

手机上的“会话”按钮打开会话抽屉，选择已有会话后返回对话；点击抽屉外部可以关闭。
“新会话”先准备新任务，发送第一条消息时才建立后端会话。底部导航进入对话、
项目、消息、记忆或文件。文件与工作设置在可关闭的面板中展示，设置里可以选择模型。
项目、记忆和消息沿用桌面工作台的业务模块、权限与确认行为。
手机消息中心顶部的会话按钮按需展开消息会话列表，正文与输入区保留更多空间；
图片、视频与表情操作保留，媒体工具栏可以横向滚动。

竖屏适合输入与日常阅读，平板和横屏适合查看较长内容。回复中的宽表格在内容区域
横向滚动。任务运行期间可以编辑下一条草稿；发送状态仍由当前运行决定。
手机软键盘打开后，确认输入框和发送按钮仍可见；需要换行时使用输入框的换行操作。

## 本地验证

仓库根目录执行 `npm run test:mobile`。使用已安装的 Node.js、Playwright Core 和 Chrome，
可以通过 `PLAYWRIGHT_MODULE` 指定已有模块路径，通过 `CHROME_PATH` 指定浏览器路径。
测试从当前仓库读取页面，在随机端口启动合成 localhost 服务并阻止外部请求，
不访问真实会话、消息、后端或模型，也不发送 QQ 消息。

测试覆盖 390×844、320×568、768×1024、1024×768 和 844×390 视口：入口参数保留、
新任务延迟创建会话、触摸导航尺寸、会话抽屉、文件与设置关闭、模型选择、
项目/记忆/消息窗口、保持连接的 HTTP SSE 过程文字与工具状态及答案增量、
运行中草稿编辑、聚焦输入时缩短视口、Markdown 宽表格局部滚动及页面无横向溢出。
截图写入本机忽略目录 `.runtime/mobile-preview/`。

自动化测试的缩短视口用于模拟键盘占用空间；它不等同于真实手机软键盘。
实机验收时，在手机和平板浏览器中检查输入焦点、软键盘展开与收起、屏幕旋转、
长回复滚动及弹窗关闭。自动化使用合成数据，真实后端连通性与模型质量需要另外确认。

## 远程访问配置与修复（2026-10-07）

Windows 前端服务的私有 `.env` 中设置允许访问的完整来源；填写协议、主机和端口，
不包含页面路径或查询参数。换电脑或换组网地址时修改这里，页面代码不需要修改。

```dotenv
LKA_WORKBENCH_ORIGINS=http://your-computer.your-tailnet.ts.net:8780
LKA_WORKBENCH_BACKEND_URL=http://127.0.0.1:8765
```

多个来源用分号分隔；空值默认不启用远程 API。本机工作台仍可访问。网关的上游固定在
前端电脑的 loopback LKA 地址，当前允许 8765/80 端口，不接收浏览器传入的代理目标。
新增网关不转发 QQ 发送或消息控制接口，也不向页面传递本机控制凭据。
远程入口依赖部署者已有的可信组网或访问保护，来源配置是入口限制，不是登录系统。

手机上的新工作区创建在前端电脑的默认父目录下，默认 Windows“文档/
Local Knowledge Agent/Workspaces”。可以配置 `LKA_SESSION_WORKSPACE_BASE` 改变默认父目录；
需要额外父目录时，用 `LKA_REMOTE_WORKSPACE_ROOTS` 声明精确目录（分号分隔）。远程请求不能
自行指定未启用的父目录。手机也能通过文件面板的“切换目录”浏览电脑上的本机磁盘与文件夹，确认后交给后端校验。
启用或修改服务配置后需要更新前端服务；已有页面刷新即可加载新脚本。

本次问题来源：旧实现从移动页面直连第二个端口，远程来源不在后端默认 CORS 范围内；
另一个前端工作区创建接口只接受 loopback 客户端。此前移动回归使用显式同源模拟后端并
直接模拟成功的目录创建，没有覆盖这两种实际失败。现在回归覆盖默认网关、独立远程域名、
旧 localhost 链接、历史列表与详情、目录创建边界以及保持连接时的实时 SSE。
历史同步失败也会显示错误，保留已有本地记录。


完成验证：Windows 原生 17 项代理/目录测试通过；移动端五种视口及独立远程域名回归通过；
桌面/桌宠聊天回归通过。通过当前已授权的 Tailscale 来源实测：页面、历史列表与历史详情、
模型列表均成功；临时工作区创建和重复创建成功，验证空目录已清理。仅更新前端服务，
现有 Tailscale 转发、WSL 后端、Java 桌宠和 QQ 桥进程保留；未启动模型任务或发送 QQ 消息。


## 手机与电脑之间传文件

底部“工作区”打开电脑文件面板。“切换目录”浏览电脑上的文件夹，确认后切换当前会话的
工作区；取消不改变目录。“上传到这里”把手机选择的任意类型文件保存到正在浏览的电脑
目录；进入子文件夹后上传就保存在该子文件夹。每个文件右侧的下载图标把文件交给手机
浏览器保存，图片、文档和其他格式均可下载，不要求能在线预览。

传输显示进度、取消、重试和目标目录。同名上传保留原文件，并给新文件加序号。
上传单文件最多 64 MiB，下载最多 128 MiB；文件面板上传不会自动给 Agent 发消息。
完整行为、接口与 Windows/WSL 边界见[跨终端文件](workspace-files.md)。

## 文件、图片与文字混合输入

输入框旁的 `＋` 打开上传菜单：可选择图片或文档，与文字一起发送，也可只发送附件。
支持系统文件选择器多选图片和文件；有文件剪贴板权限时，也可以混合粘贴。
每轮图片与文档合计最多 4 个附件，文档最多 64 MiB，图片上传最多 10 MiB。
输入区显示缩略图/文件名称、大小、上传解析状态、解析提示和移除按钮。
会话历史保留原图查看和文档下载。详见[混合附件输入](image-input.md)。

移动端继续使用共享 `chat.js`：新消息自动滚动、真实流式答案、模型过程与工具调用、
可编辑的忙碌输入框、会话历史和工作区绑定均沿用工作台逻辑。
手机/平板保留触屏抽屉与底部导航。文件选择器及系统剪贴板权限需要实机确认。
