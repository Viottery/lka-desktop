# 会话列表交互修复 · 2026-10-06

## 已实现

- 刷新、重新打开任务页、连续点击“新会话”时，复用可用的空白任务页；纯本地旧空白记录收敛，不继续堆积。
- 保留未发送草稿、手工标题、指定工作目录、项目中主动创建的会话，以及已有消息、运行记录或审批状态的会话。
- 清理后端历史空白前，检查来源、完整详情、工作目录为空，以及后端是否支持条件删除。后端离线、详情/目录不可读或条件不符时保留。
- 条件删除在数据库事务内检查原始更新时间、消息与运行记录；冲突返回 409。已有后端会话进入回收站，可恢复；不删除目录和文件，不实现超时物理清理。
- 会话卡片标题、时间、消息数与留白区域都可点击选择；重命名/删除保持独立，键盘焦点覆盖整张卡片。
- 项目新建会话记录显式用途，工作目录选择记录保护标记；静态资源更新版本号。

## 使用范围

快速任务页与工作台使用同一聊天实现；浏览器验证使用 Windows Chrome 和隔离的合成 HTTP 服务，不向真实 Agent 发任务。JavaFX 宿主交互使用同一页面，但实际鼠标手感仍需在桌面体验确认。

对旧后端缺少条件删除能力的情况，前端仅复用/收敛本地空白，不发送自动删除。历史空白清理随前端会话同步触发，不执行数据库全库清扫。
